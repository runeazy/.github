# RunEazy

Software for running a business, built on an open platform.

- **[runeazy-sdk](https://github.com/runeazy/runeazy-sdk):** client SDKs for Node, React, Android and iOS (Apache-2.0)
- **[runeazy-services](https://github.com/runeazy/runeazy-services):** open platform services: notifications, forms, links and scheduling (AGPL-3.0)
- **[runeazy-docs](https://github.com/runeazy/runeazy-docs):** build a docs site and host it anywhere (Apache-2.0)
- **[runeazy-learn](https://github.com/runeazy/runeazy-learn):** computer science you can see, in 3D lessons

Everything runs on any cloud, with any standard OAuth issuer. See each repository's
`CONTRIBUTING.md` to take part, and [runeazy.com](https://runeazy.com) for the products.
