# Getting help

- **Questions and ideas:** open a discussion or an issue in the repository it concerns.
- **Bugs:** open an issue with the bug report form, with a version and the smallest steps that
  show it.
- **Security problems:** never in an issue. See [SECURITY.md](./SECURITY.md).
- **RunEazy's hosted products:** support is through [runeazy.com](https://runeazy.com).

Maintainers aim to reply within a week. There is no paid support for the open-source projects.
