# Code of Conduct

Every RunEazy project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, and keep discussion about the work. Harassment,
insults and personal attacks are not accepted in any project space.

Report unacceptable behaviour to **<hello@runeazy.com>** (subject: Conduct). Reports are read only by the
maintainers and handled in confidence.
